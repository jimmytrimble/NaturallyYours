# Naturally Yours Brand Style Guide

## Color Palette

### Primary Colors

#### Pink (Primary Accent)
- **Name:** nyPink
- **Hex:** #F28CBD
- **RGB:** 242, 140, 189
- **Usage:** Primary buttons, accents, badges, icons

#### Light Pink (Secondary)
- **Name:** nyLightPink
- **Hex:** #FBDCE8
- **RGB:** 251, 220, 232
- **Usage:** Backgrounds, secondary elements

#### Soft Pink (Background)
- **Name:** nySoftPink
- **Hex:** #FDF2F7
- **RGB:** 253, 242, 247
- **Usage:** Very light backgrounds, subtle sections

### Neutral Colors

#### Black
- **Name:** nyBlack
- **Hex:** #000000
- **RGB:** 0, 0, 0
- **Usage:** Primary text, headers, navigation items

#### White
- **Name:** nyWhite
- **Hex:** #FFFFFF
- **RGB:** 255, 255, 255
- **Usage:** Backgrounds, card backgrounds, text on dark

#### Gray
- **Name:** nyGray
- **Hex:** #808080
- **RGB:** 128, 128, 128
- **Usage:** Secondary text, captions, icons

#### Light Gray
- **Name:** nyLightGray
- **Hex:** #F5F5F5
- **RGB:** 245, 245, 245
- **Usage:** Input fields, subtle backgrounds

## Typography

### Logo Font
- **Style:** Handwritten/Script
- **Weight:** Medium
- **Size:** 34pt (default), 42pt (hero)
- **Color:** Black on light backgrounds, White on dark
- **Usage:** Brand name "Naturally Yours"

### Headings
- **Style:** System Bold
- **Sizes:** 
  - H1: 28pt
  - H2: 24pt
  - H3: 20pt
  - H4: 18pt
- **Color:** nyBlack
- **Usage:** Section titles, page headers

### Body Text
- **Style:** System Regular
- **Size:** 16pt
- **Color:** nyBlack (primary), nyGray (secondary)
- **Usage:** Product descriptions, content

### Captions
- **Style:** System Regular
- **Size:** 14pt
- **Color:** nyGray
- **Usage:** Labels, metadata, small text

## Spacing

### Section Spacing
- Between major sections: 30-40pt
- Within sections: 20pt
- Between related items: 12-16pt

### Padding
- Cards: 12-20pt
- Buttons: 14-16pt vertical, 24-40pt horizontal
- Screen edges: 20pt

## Corner Radius

- **Cards:** 12pt
- **Buttons:** 8pt
- **Images:** 12pt (large), 8pt (small)
- **Circles:** 50% (for profile images, brand logos)

## Shadows

### Card Shadow
- **Color:** Black @ 8% opacity
- **Radius:** 8pt
- **Offset:** (0, 4)
- **Usage:** Product cards, collection cards, testimonials

### Elevation Shadow
- **Color:** Black @ 5% opacity
- **Radius:** 4pt
- **Offset:** (0, 2)
- **Usage:** Subtle elevation, buttons

## Component Styles

### Buttons

#### Primary Button
- **Background:** nyBlack
- **Text:** nyWhite
- **Font:** 16pt Semibold
- **Padding:** 14pt vertical, 40pt horizontal
- **Corner Radius:** 8pt

#### Secondary Button
- **Background:** nyPink
- **Text:** nyWhite
- **Font:** 15pt Semibold
- **Padding:** 16pt vertical, 24pt horizontal
- **Corner Radius:** 8pt

### Cards

#### Product Card
- **Width:** 180pt
- **Background:** nyWhite
- **Shadow:** Card shadow
- **Corner Radius:** 12pt
- **Padding:** 12pt

#### Testimonial Card
- **Width:** 280pt
- **Height:** 200pt
- **Background:** nyWhite
- **Shadow:** Card shadow
- **Corner Radius:** 12pt
- **Padding:** 20pt

### Input Fields
- **Background:** nyLightGray
- **Text:** nyBlack
- **Font:** 15pt Regular
- **Padding:** 16pt
- **Corner Radius:** 8pt
- **Border:** None

## Logo Usage

### Primary Logo
- Use on light backgrounds
- Color: Black
- Minimum size: 120px wide
- Clear space: 20pt around logo

### Reversed Logo
- Use on dark backgrounds (black, dark images)
- Color: White
- Maintain same sizing and spacing

### Small Logo (Navigation)
- Size: 22pt
- Use in navigation bars
- Always maintain readability

## Image Guidelines

### Product Images
- **Aspect Ratio:** 1:1 (square)
- **Recommended Size:** 400×400px
- **Format:** PNG or JPEG
- **Background:** White or transparent

### Collection Images
- **Aspect Ratio:** 6:5 (landscape)
- **Recommended Size:** 600×500px
- **Format:** JPEG
- **Style:** Lifestyle or product shots

### Brand Logos
- **Aspect Ratio:** 1:1 (square)
- **Recommended Size:** 300×300px
- **Format:** PNG with transparency
- **Padding:** Include internal padding in logo

### Hero Image
- **Aspect Ratio:** 2:1 (landscape)
- **Recommended Size:** 1200×600px
- **Format:** JPEG
- **Style:** High-quality lifestyle imagery

## Accessibility

### Color Contrast
- Text on white: Use nyBlack (21:1 ratio) ✅
- Text on pink: Use white or black depending on shade
- Minimum contrast ratio: 4.5:1 for normal text

### Font Sizes
- Minimum body text: 14pt
- Minimum touch target: 44×44pt
- Support Dynamic Type

### Alternative Text
- All images should have descriptive alt text
- Decorative images: Empty alt text

## Best Practices

### Do's ✅
- Use pink as an accent color, not overwhelming
- Maintain ample white space
- Keep text readable with good contrast
- Use consistent spacing throughout
- Match website aesthetic

### Don'ts ❌
- Don't use too many colors beyond the palette
- Don't make text too small
- Don't overcrowd the interface
- Don't use low-quality images
- Don't deviate from established patterns

---

**Note:** These guidelines are based on the Naturally Yours website design and should be consistently applied across the mobile app for brand cohesion.
